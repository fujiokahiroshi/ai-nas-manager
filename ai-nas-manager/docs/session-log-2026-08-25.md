## 3. 映像セマンティックタグ付けの予備実験

詳細は`ai-nas-manager/docs/semantic-tagging-experiment.md`参照。要点:

- 目的: media_rendererが「再生する」のに対し、こちらは**映像の中身を理解し
  言語化する**実験。将来のAI NAS managerの意味検索・要約機能の土台。
- 途中、2回大きく方向を誤った:
  1. シーン説明文を映像にテキストとして焼き込み、同じ文字列をタグ付けロジックに
     戻す、という循環したテスト(「あほか」と指摘され訂正)
  2. 静止画のピクトグラムを使う案 → そもそも「フレームが大量にあって1枚1枚は
     処理できない」という本質的な問題を素通りしてしまっていた(「話が逆」
     「それもわからずになにをしてるの」と指摘され訂正)
- 正しい理解: 映像は大量のフレームから成り、フレーム単位の解析は非現実的。
  そこで**パワーエレクトロニクスのaverage value modeling(平均値法)**からの
  類推で、以下の3段階パイプラインを設計した:
  1. 安価な信号(ffmpegの組み込みシーン変化検出)だけで、全フレームを見ずに
     少数の候補境界(fragment)を直接抽出する
  2. 絞り込まれた少数のfragmentの代表フレームだけを高速にタグ付け(言語化)する
  3. fragmentのタグを統合し、映像全体レベルの高次の意味解釈につなげる
- 実写映像(LEGO Mindstorms EV3の実機デモ映像、ユーザーのOneDrive上から発見、
  48秒)で実際に検証: シーン変化検出で9個の候補境界を抽出(全フレーム約1440枚
  から大幅削減)、そのうち8個が実際に意味のある変化(カメラのカット・人の手の
  介入・ロボットの姿勢変化)に対応していた。Claudeが各fragmentを見て言語化し、
  それを統合して映像全体の説明文を生成 → **これがユーザーの求めていた
  「映像tag」の最終形として確認された**。

## 4. 実機Tunerと字幕放送による学習構想

- 採用予定の実機Tunerは、**日本の放送規格を30年以上手がけてきた会社が開発**
  したもの。SoCはAmlogicだが、ファームウェアは全て自社製、CLI/MCP対応も
  自社で実施予定とのこと。
- これを踏まえ、ユーザーから新しいアイデア: **地上デジタル放送の字幕放送を
  正解データとして使い、上記の映像言語化パイプラインの精度を検証・学習する**。
  字幕は映像と同期した人間製の正解データが無料で得られるため、新規のラベル付け
  作業が不要になる。ファームウェアを自社コントロールできるため、字幕データの
  取り出し方も自分たちで設計できる = 実現可能性の高い計画。
- 詳細は`semantic-tagging-experiment.md`7節、`media-renderer-design.md`3.3節。
  現時点ではv-01(virtual_tunerダミー)には未適用、将来の方向性として記録。
