# Local experiment tools

The binaries in this directory are intentionally not committed.

For the RTSP experiment, download the official MediaMTX Windows amd64 archive:

- Version: v1.21.0
- Archive: `mediamtx_v1.21.0_windows_amd64.zip`
- SHA-256: `8a58a9b8c25ee99a96c23dc0a17f39ace3072c01d2e148329073c64ddf83493d`
- Extract executable: `tools/mediamtx/mediamtx.exe`

FFmpeg must also be installed and its executable passed with `--ffmpeg`.
